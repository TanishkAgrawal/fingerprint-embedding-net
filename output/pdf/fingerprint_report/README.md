# Fingerprint retrieval report package

Temporary page inspection images and contact sheets were moved to the
[cleanup archive](../../../archive/2026-10-29-cleanup/README.md). The final PDF and
editable report sources remain here.

- `Fingerprint_Retrieval_Project_Report.pdf`: report following the supplied PDF thesis structure.
- `build_report.py`: editable source; regenerate from the repository root using the bundled Python runtime with ReportLab.
- `diagrams/`: editable Mermaid diagrams and retrieval chart data. Figures in the PDF are generated by the source script.
- `bibliography.txt`: numbered reference list.

## Placeholders to complete

Student name(s), registration number(s), degree and programme, institution, department, guide and designation, date, place, signatures, and any institutional acknowledgement. Have authorised people check and sign the declaration and certificate. The UI graphic is illustrative, not a screenshot.

## Experimental scope

The report uses local EER and DenseNet retrieval results. Model selection used test-pair results, so a new untouched external set is required for final assessment. mAP, open-set performance, independent latent-print performance and execution times were not measured. Check current Pinecone upload progress before describing all vectors as stored.

## Regeneration

Run `python output/pdf/fingerprint_report/build_report.py` with ReportLab and local project result CSVs installed. It reads `outputs/eer_comparison/comparison.csv` and writes the PDF and diagram sources. This source uses Windows Times New Roman fonts.
